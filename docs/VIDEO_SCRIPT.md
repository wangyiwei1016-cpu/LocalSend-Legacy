## 二、拍摄 / 录屏准备

### 设备与场景

- 红米 1（2013022，Android 4.2.1）一台，保持亮屏、关闭无关通知
- Windows 电脑一台，和手机连同一个 Wi-Fi
- 手机支架 / 俯拍支架，补一盏柔光灯
- 领夹麦或 USB 麦；房间关窗、关风扇
- 电脑端 OBS：1920×1080、30fps，录 PC 屏幕

### 录屏说明（重要）

红米 1 是 API 17，系统自带的 `adb shell screenrecord` 要 API 19+，**不能直接录**。建议：

1. **真实操作**用俯拍或手机支架拍手机屏幕，保留真实反光和手指；
2. **清晰 UI 特写**用 API 19+ 的模拟器（或另一台新安卓）录屏，只截取 UI，不冒充真机；
3. 或者用高分辨率截图做 2–3 秒的缓慢推拉（Ken Burns），别长时间静止；
4. PC 端用 OBS 录「发送/接收」窗口，后期和手机画面左右分屏。

> 混剪时在角落标注「真机操作」/「模拟器界面」，避免观众误会。

### 录制前检查

- [ ] 手机别名改成 `Redmi 1`（设置 → 通用 → 设备名称）
- [ ] 高级材质打开；主题选「雾蓝」；背景图先不设，拍完默认效果再设背景
- [ ] 准备两个测试文件：一张 JPG、一个 APK（用本项目 release APK 即可）
- [ ] 清空接收历史，拍「第一次接收」更干净
- [ ] 电脑端 LocalSend 关闭加密（设置 → 高级设置 → 网络）
- [ ] 手机和电脑的 IP、Wi-Fi 名称确认；拍进去前想好是否打码
- [ ] 先完整走一遍流程，确认接收确认框、完成弹窗、历史都能出现

## 四、口播全文（提词器版）

> 约 900 字，按 3 分 30 秒、偏慢语速写。可按实际删减。

这台红米 1，2013 年发布，Android 4.2.1。官方 LocalSend 早就装不上了。

但我今天要用它，和电脑互传文件。不登录，不经过云盘，只靠同一个 Wi-Fi。

为什么装不上？新版本地传输大多走 HTTPS，而 Android 4.2 的系统 TLS 只到 1.0，握手过不去。LocalSend 协议本身允许明文 HTTP。于是有了这个独立实现：minSdk 8，Android 2.2 起，release APK 只有 145 KB。它不是官方客户端，是一个兼容实现。

安装很简单，APK 侧载。打开接收页，本机名称、端口 53317，服务已经在跑。

电脑上选好文件，点发送。手机弹出确认，接收。

传完不是只弹个提示。图片有缩略图，APK 能读出应用图标，点一下直接打开。

右上角时钟是接收历史。图片、视频、音频、APK、PDF、压缩包都有自己的图标。可以打开，也可以只删记录，或者连源文件一起删。

反过来，手机发给电脑。文件、媒体、文本、剪贴板，还有应用。它会读取已安装应用，直接发 APK；顶部可以切换显示系统应用。选一个应用，再点电脑，电脑确认，安装包就过去了。

界面不是简单套壳。6 套低饱和莫奈色，每套都有浅色和深色；深色模式会连同卡片、图标、对话框一起切。

高级材质打开后，底栏变成悬浮玻璃，历史记录、通过链接接收、六宫格都有半透明雾面和细包边。

还能换背景图，模糊 0 到 100，亮度 0 到 200，拖完实时看效果。

先把限制说清楚：明文传输只适合可信局域网；手机发给官方客户端时，要在官方端关掉加密；文件夹和断点续传还不支持。应用只发基础 APK，split APK 只发 base。兼容性我在红米 1 的 4.2.1 上实测；2.2 没有真机，靠 lint 和 Dalvik 交叉验证，建议你在真 2.3 上再试。

项目 MIT 开源，APK 在 GitHub Release，版本 1.2。下一台想让我折腾什么老设备，评论区点名。

## 五、剪辑与包装

- **节奏**：每 5–8 秒换一次画面；操作类镜头保留手指和点击声，不要全程配乐盖住
- **分屏**：左电脑、右手机；手机画面保持 9:16，不要拉成 16:9
- **字幕**：关键词大字（端口、145 KB、6 套主题），口播全文放小字或关掉
- **音乐**：轻钢琴/Lo-fi，音量 -22 LUFS 左右；关键操作处可留 0.5 秒环境音
- **转场**：硬切为主，最多用淡入淡出；不要花哨转场
- **色彩**：手机实拍和 PC 录屏尽量统一白平衡；截图特写可轻微锐化
- **免责声明**：开头或简介固定一行「独立实现，非 LocalSend 官方」
- **打码**：Wi-Fi 名称、真实 IP、个人文件名；测试文件统一用 `LocalSend-preview.jpg` / `LocalSendLegacy-1.2.apk`
